Dover sole harvest projections

Dover sole is the Tier 3a component of the deepwater flatfish complex. This document provides the methods used to complete the 2026 harvest projections for Dover sole. The other components of the complex are Tier 6 and no projections are necessary. Prior to running this code, I created a new folder: C:.mcgilliard\2026_deepwater_projections

I then copied in spm.dat, tapcar.dat, and the data folder with its contents from the folder for the previous year’s projections: C:.mcgilliard\2025_projections

I did not copy in spm.exe, but rather got the latest version from the spmR repository. The current location is: https://github.com/afsc-assessments/spmR However, we are supposed to move all of our operational repositories to be in the Enterprise, so check to see if it’s there if it’s not at this link.
